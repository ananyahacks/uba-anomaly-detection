# User Behavior Anomaly Detection (UBA)

This project implements a User Behavior Anomaly Detection system using
synthetic data generation and unsupervised machine learning.

## Tech Stack
- Python
- Faker (Synthetic Data)
- Pandas, NumPy
- Scikit-learn
- Isolation Forest
- One-Class SVM
